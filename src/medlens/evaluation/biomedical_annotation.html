Ручная разметка релевантности статей

Для каждого вопроса прочитайте критерий релевантности, заголовок и полную аннотацию статьи. Все оценки изначально пустые. Модельных оценок и объяснений здесь нет.

  • 0 — не релевантна: статья не помогает ответить на заданный вопрос.
  • 1 — частично релевантна: полезна для части вопроса, но нужная популяция, сравнение, исход или другой ключевой элемент не совпадает либо раскрыт неполно.
  • 2 — напрямую релевантна: даёт непосредственные данные для ответа по указанному критерию.
  • Не могу оценить: имеющихся данных или вашей уверенности недостаточно. Это отдельное решение, а не оценка 0.

Изменения сохраняются только в этом браузере. Кнопки экспорта скачивают локальный JSON; приложение не отправляет оценки по сети. По ссылке PubMed можно открыть исходную статью.
